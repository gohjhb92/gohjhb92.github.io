Featured Portfolio Project Flagship

IncubatorOS

I built IncubatorOS to see what purpose-built tooling for incubation operations would actually look like. It has four modules: a grant evaluator that scores startup applications against configurable criteria, a founder CRM for tracking cohort progress and milestone sign-offs, a pilot matching interface that maps startup capabilities to corporate problem statements, and a batch outreach tool for stakeholder communications.

The grant evaluator came directly from reviewing around 30 TZ APAC applications — I wanted scoring criteria to be explicit and consistent rather than held in someone's head. Built on Claude API with sample data throughout.

Personal Data Project Live App

BTO Ballot Tracker

Singapore HDB BTO ballot odds calculator covering all 20 BTO exercises from Feb 2020 to Oct 2025. Pulls historical subscription rate data across estate types, flat types, and applicant categories to estimate ballot odds and visualise trends. Features an interactive Leaflet map with per-town project pins, a historical average heatmap, and estate-type comparison charts. Built with Next.js 14, TypeScript, Tailwind CSS, Recharts, and react-leaflet — deployed on Vercel.
