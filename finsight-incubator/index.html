product.scope

What it does

Startup Intake

Captures startup name, sector, stage, founders, country, traction, funding ask, description, and regulatory risk.

Screening Dashboard

Ranks digital finance startups by AI score, recommendation, traction, country, sector, and funding ask.

Startup Detail

Shows scoring dimensions, strengths, risks, due-diligence questions, and incubation recommendation.

Scoring Model

Founder Quality, Market Opportunity, Product Differentiation, Regulatory Readiness, Traction, and Ecosystem Fit.

AI Memo Generator

Generates structured incubation memos with mentor suggestions and final recommendation logic.

Exportable Output

Memo pages are styled for browser print and PDF export, suitable for internal review packets.

02

memo.generator

Structured incubation memo output.

The memo generator produces an executive summary, startup overview, market opportunity, founder assessment, product and technology assessment, regulatory risk, digital finance relevance, incubation fit, suggested mentors, due-diligence questions, and final recommendation.

The implementation includes a server API route designed for OpenAI integration using an environment variable for the API key. If the key is missing, the system returns a deterministic mock memo so the prototype remains usable without exposing secrets to frontend code.
